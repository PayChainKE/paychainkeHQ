# Welcome

## Project info

This repo contains the Paychainke Dashboard application.

## How can I edit this code?

Use your preferred IDE locally:

```sh
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
npm install
npm run dev
```

## What technologies are used for this project?

- Vite
- TypeScript
- React
- Tailwind CSS

## Deploy

Build with `npm run build` and deploy the output from the `dist` folder to your hosting provider.

For domain configuration, consult your hosting provider's docs.
