Bitcount Prop Double Ink font files

This folder contains placeholder files for the Bitcount Prop Double Ink
font used by the Paychain web app.

Please replace the placeholder files with the real font files you have:

- BitcountPropDoubleInk-700.woff2
- BitcountPropDoubleInk-700.woff

After replacing, rebuild or restart the dev server to see the real font.

Notes:
- Keep the filenames as above or update the @font-face src paths in
  apps/web/src/index.css to match your filenames.
- If you have additional weights (400, 500, 800, etc.), add corresponding
  @font-face blocks in apps/web/src/index.css.
